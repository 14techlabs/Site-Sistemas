# Visual baseline screenshots

Script versionado: `screenshot-baseline.mjs`. Ele usa Playwright Chromium e captura cada URL em 1440×900 e 390×844 com movimento reduzido e animações desativadas. Defina `BASE_URL_14TECH`, `BASE_URL_SUAPRE`, `BASE_URL_SIGAC`, `BASE_URL_GARDIAN` e `BASE_URL_FROTASON` para as portas corretas antes de executar. O script não foi executado durante a montagem do ZIP.

Para executar futuramente, instale Playwright no ambiente de desenvolvimento e rode `node tooling/playwright/screenshot-baseline.mjs`.
