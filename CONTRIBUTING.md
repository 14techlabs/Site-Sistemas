# Contribuição

Use Conventional Commits para alterações da migração: `chore(monorepo): ...`, `feat(ui): ...`, `fix(suapre): ...`, `docs(migration): ...`, `refactor(14tech): ...`, `test(visual): ...`. Prefira commits pequenos e com escopo explícito. Não altere CSS legado de 14tech/SUAPRE nem estilos dos outros produtos sem aprovação específica.
